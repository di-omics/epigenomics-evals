## What changed from Figure 4a

The exact comparison in Figure 4a is not public, so the pilot uses the nearest one that is.

- **Thresholds became callers.** Figure 4a sweeps settings within each peak caller (MACS2 q-values, SEACR top fractions). Only the peak sets at the final settings were deposited. The pilot compares the 2 callers at those final settings on the same library.
- **The library.** The primary instance uses the first-round Diagenode 1:50 library that the paper's code repository ships as its worked example, because its files, its Picard report and the authors' rendered notebook are all public. The paper's 6 benchmarking libraries and 4 more first-round libraries are the 10 check instances.
- **The blacklist.** The paper's Methods name ENCODE file ENCFF000KJP. The repository's code uses the hg19 blacklist v2, and the notebook's blacklist counts match that file. The pilot follows the code.
- **The rule.** The paper states the aim: maximise ENCODE capture while keeping precision above 75%. The pilot writes it as a rule with 4 possible answers.
- **The files.** Reduced to 3 columns, sorted, relabelled A and B. No interval was changed.
